# Form checklist

Report only failing items, with their location.

## Figures and tables

- Numbered in order of first citation in the text; every figure, panel and table is cited.
- Each legend stands alone: title, what is shown, n, statistical test, error bars, scale bars, units.
- Abbreviations in a figure or table are defined in its legend.
- Panel labels in the legend match the figure.
- Numbers in the text match those in figures and tables (flag mismatches as points to discuss).
- Supplementary items are numbered and cited consistently.

## References

- Every in-text citation is in the bibliography, and every bibliography entry is cited.
- One consistent citation style; complete entries (authors, year, title, journal, volume, pages or article number).
- DOI present when the style requires it; preprints marked as such, and updated if published (check, never guess).
- No broken LaTeX citation keys (`[?]`) or unresolved Word fields.

## Links, data and code

- URLs and DOIs are well formed and point to the intended resource; flag dead or suspicious links.
- Data availability: accession numbers (GEO, SRA, ENA, PRIDE, Zenodo...) present and formatted.
- Code availability: repository and version or release (tag, commit or DOI).
- Software and databases cited with versions; genome build and annotation release stated.

## Text consistency

- Abbreviations defined at first use (abstract and main text separately), then used consistently.
- Consistent terms, gene and protein nomenclature (italics for genes where the field requires it), species names in italics.
- Units: SI, space between value and unit, consistent decimal separator and number format.
- Consistent spelling variant (US or UK English) throughout.
- Cross-references (sections, equations, figures) resolve correctly.

## Structure

- Sections expected by the journal or by convention are present
  (Abstract, Methods, Data availability, Code availability, Author contributions, Funding, Competing interests).
- Abstract within the word limit when known.
- AI use statement if the journal requires one.
