# AI Disclosure templates

Pick ONE level that matches how AI was actually used in the project.
Paste it as a `## AI Disclosure` section at the end of the project README, before the license section.
Use a separate `AI_DISCLOSURE.md` file only if the statement is long or if a journal or funder requires it.

---

## Level 1: Documentation

> Use only if it is strictly true: no line of source code was written by an AI tool.

```markdown
## AI Disclosure

The source code of this project is 100% human-written.
AI was used solely to assist in writing this README, generating inline code comments, and translating documentation.
```

---

## Level 2: Assisted

```markdown
## AI Disclosure

AI tools were used as advanced autocomplete during development.

- **Human Ownership:** all logic, architecture and complex problem-solving were authored and directed by the developer.
```

---

## Level 3: Augmented

```markdown
## AI Disclosure

AI tools were used to:

- Generate boilerplate and utility functions.
- Refactor code.
- Draft unit tests and documentation.

**Verification:** every AI-generated contribution was manually reviewed, debugged and integrated.
```

---

## Level 4: Driven

```markdown
## AI Disclosure

This project was created as an exploration of AI's generative capabilities.

- **Process:** most of the code was generated by large language models from detailed prompts and architectural requirements.
- **Human Role:** architect and prompt engineer: definition of scope, integration troubleshooting, final quality assurance.
- **Responsibility:** the authors take full responsibility for the code and results.
```
